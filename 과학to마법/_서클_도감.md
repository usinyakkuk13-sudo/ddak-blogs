# 과학to마법 — 서클 도감 (채널 세계관 기준표)

**서클 기준 = D&D 5판 주문 레벨 (0~9)을 그대로 서클로 씀.**
- 이유: 한국 웹소설은 작품마다 서클이 제각각 → 댓글 싸움 나면 "D&D 5판 기준"으로 바로 정리됨. 판타지 덕후·패션 과학자 둘 다 납득.
- 9서클 = 인간 마법의 끝. 10서클은 "신의 영역" 특집용으로만 아껴 둠.
- 레벨은 기억 기반 정리 → **대본 쓸 때 SRD로 재확인**.
- ★ = 마법 재료(상품 연결) 웃김 정도. ★★★ = "상품연결 뭐임 ㅋㅋ"
