# 문명 이기 지수 — 시즌1 구상 (2026-11-05 초안)

## 컨셉 한 줄
"지금 1만 원짜리 그 물건, 처음 나왔을 땐 차 한 대 값이었다" — 처음 등장했을 때의 가격·위상을 지금 돈으로 환산하고, 지금 값과 비교해 **문명 이기 점수(×N배)**로 감정한다. 마지막 컷 = 오늘의 문명템(상품 연결).

## 채널
- 과학to마법과 **분리된 별도 채널** 권장 (가제: **문명 감정소**). 과학to마법 = 패션과학·개그, 이쪽 = 가치·향수·"살 만하다" — 타깃과 상품 연결 성격이 다름.
- 진행: 해설 = 형님 목소리 / 감정사 할아버지 = 반응 창 + 말풍선.

## 고정 포맷 (40~45초)
1. 훅: "지금 손에 든 그거, ○○년엔 얼마였을까?" (실물 사진)
2. 첫 등장 (세피아 화면): 누가 만들었고, 누가 썼나 = 위상
3. 그때 가격
4. **3지선다**: 지금 돈으로 얼마?
5. 정답 + 체감 비교물 (경차 ○대 / 월급 ○달 / 쌀 ○가마)
6. 반전: "근데 지금은?" (밝은 화면)
7. 지금 가격 (+ 대체한 물건들이 있으면 합산)
8. **문명 이기 점수 ×N 감정 도장**
9. 오늘의 문명템 카드 + "다음 감정 물건은 댓글로" (채택 시 **"의뢰인 @닉네임"** 크레딧 — 진품명품 감성)

## 점수 공식
문명 이기 점수 = (처음 가격의 현재가치) ÷ (지금 같은 기능 제품 가격). 스마트폰처럼 여러 물건을 삼킨 경우만 대체품 합산.
- 해외 물건: 미국 CPI 환산 → 당월 환율. 국내 물건: 당시 **월급·쌀값·짜장면값 대비**가 더 와닿음(한국은행 CPI 병기).
- 출처 2곳 이상 확인, 숫자는 "약"으로 반올림. 대본 파일 아래에 출처 고정.

## 순서 (전략)
- **1단계 — YPP 전 (구독자 모으기)**: 점수가 터무니없이 크고 물건이 싸서 "어 진짜?"가 나오는 것부터.
  1. 볼펜 → 2. 손목시계 → 3. 계산기 → 4. 휴대폰(샘플 완성본) → 5. 알루미늄 → 6. 저장장치
- **2단계 — YPP 후 (태그 켜고)**: 문명템이 실제로 사고 싶은 가전·생활템.
  전자레인지 · 흑백TV(빔) · 전구 · 후추 …
- **계절 편성**: 여름(5~7월) 선풍기·에어컨·냉장고 / 겨울(11~2월) 난방템(전기장판·히터 — 역사 확인 후).
- 모든 편 마지막 컷에 문명템 카드 고정 → YPP 후 기존 영상까지 일괄 태그.
